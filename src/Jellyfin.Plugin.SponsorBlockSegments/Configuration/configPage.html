SponsorBlock Segments

Turns SponsorBlock data into Jellyfin media segments, so sponsors, intros, recaps and self-promotion get a skip button. It reads the [SponsorBlock]: chapters yt-dlp embeds, and can fall back to the SponsorBlock API for files that have none.

Every segment in a file is emitted — a video with seven sponsor reads produces seven segments. To have these used ahead of another provider, order or disable providers per library under Libraries → (library) → Media Segment Providers.

When off, the provider reports that it supports nothing. Segments already stored stay where they are until the next scan.
Chapters need no network and are exactly what was embedded at download time. The API is always current and returns precise start and end times, but needs a YouTube video id in the filename.

What gets scanned

An allowlist. With nothing selected this plugin produces no segments at all, so it cannot put SponsorBlock segments on ordinary television by accident. Selecting a series covers every season; select individual seasons to narrow it.

Category mapping

What each SponsorBlock category becomes. Jellyfin has five segment types, so several categories share one; Ignore produces no segment and leaves the chapter alone.

Advanced

Stops a stray one-frame submission becoming a skip button. 0 disables the check.
Kept longer than a normal answer on purpose: in a YouTube library a large minority of videos have nothing submitted, and without this every scan asks about all of them again.
